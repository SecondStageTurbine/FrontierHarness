Frontier 0.19.0: other machines, and a sandbox

- Environments (Settings → Environments): pair another computer running Frontier with its pairing link, then switch to it and work on its projects from this window. Its agents run there, on its files; replies stream back live.
- Sandbox (Project settings): confine every agent's file changes to the project folder, enforced by Windows integrity levels, whatever the posture; and limit network access to the agent's own service or an allowlist, with the refused hosts shown on each turn.
- Pairing codes gain a Copy link button, which is also how another Frontier pairs.
