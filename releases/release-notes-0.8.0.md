Frontier 0.8.0 — polish, and a new icon

- Adaptive is the default agent whenever one is connected; a manual pick holds only while the project stays open.
- Sessions are named by their first reply, unless you rename them yourself.
- A context meter under the composer shows how much of the transcript limit the conversation uses, and Compact replaces the earlier messages with a summary the agent writes.
- ArrowUp walks back through your earlier messages; Ctrl+Shift+S stashes a draft, and a Stash chip puts it back.
- Right-click a project to open it in VS Code or Cursor, or show it in Explorer.
- New application, taskbar and installer icon.
