## Frontier 0.27.74

- A project using a fresh Edge or Chrome can switch its agents' browser tools from Playwright to agent-browser, in the Preview panel under **Tools**. Page reads came to about a third of the size on the page measured, for a larger tool list.
- A sandboxed project stays on Playwright so the sandbox still covers its browser. If agent-browser cannot start, the turn says so and uses Playwright.
