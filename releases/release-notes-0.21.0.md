Frontier 0.21.0

- Track records: Frontier now remembers how each agent actually did. Team tasks it finished or failed, fixes the lead sent back, running out of context, and Adaptive turns it completed or had to hand to a stronger agent all count.
- After three tasks, the record moves the agent's default strengths: up one for a clean record, down one or two for a poor one. Numbers you set yourself in the agent's Adaptive routing profile still win.
- The team lead sees each agent's record in the roster (for example "track record: 5 of 8 tasks accepted first time, 1 failed"), and so does Agents & Providers, on each agent's card.
- Changing an agent's model identifier starts its record again, so a new model is not judged by the old one's results.
