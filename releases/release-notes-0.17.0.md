Frontier 0.17.0: fuller pull requests

- Review a pull request from the Changes panel: approve, comment or request changes, with an agent's draft to start from.
- Request reviewers, toggle labels and change the base branch; see each reviewer's latest verdict.
- Merge now (squash, merge commit or rebase) or turn on auto-merge, and turn it off again.
- Stacked pull requests: open one on another pull request's branch, and see the whole stack.
