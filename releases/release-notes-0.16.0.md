Frontier 0.16.0: shortcuts, VS Code themes, and your past conversations on first run

- Keyboard shortcuts (Settings → General): every shortcut can be rebound or cleared, with new ones for the sidebar, each panel, all projects, resume from CLI and settings; defaults follow VS Code.
- Import a VS Code theme: pick a colour theme installed in VS Code, Cursor, Windsurf or VSCodium, or a theme .json file, and Frontier takes its colours.
- First-run setup now offers the folders Claude Code and Codex already have conversations about; tick them to add each as a project with its conversations imported.
