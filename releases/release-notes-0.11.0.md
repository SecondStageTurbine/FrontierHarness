Frontier 0.11.0 — team mode, pull requests, and working memory

- Team mode: a lead agent plans the work, other agents do the tasks in parallel worktrees, and the lead reviews and replies.
- Pull requests from the Changes panel through the GitHub CLI: create, watch checks and review, hand review comments to the agent.
- Edit from here: rewind the conversation and the folder to before one of your messages, then resend it changed.
- Context chips: reference a file, selected lines, terminal output or a diff beside your message instead of pasting.
- Worktree setup command and files copied into new worktrees; dev server start, stop, restart and output in the Preview panel.
- Snooze sessions; archive idle sessions automatically; Remember this session adds notes to the project memory every agent sees; workspace rules for every agent.
- Credentials: variable names from .env files, and .env kept away from Claude under every posture.
- Agent tool versions with one-click npm updates; import past Claude Code and Codex conversations for a project.
- Up to 100 attachments, images to 10 MB, other files to 50 MB; long pastes become a text attachment.
