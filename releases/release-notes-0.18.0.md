Frontier 0.18.0: Frontier on your phone

- A layout for phones over remote access: one column, projects in a drawer, full-screen panels and dialogs.
- Pair a phone by scanning a QR code in Settings → Remote access; it opens Frontier signed in, with no password to type. The code works once, for ten minutes.
- Push notifications through the free ntfy app: when a turn finishes, fails, or an agent is waiting on you. Tapping one opens the conversation.
- Narrow desktop windows keep the sidebar and panels instead of hiding them.
