## Frontier 0.27.72

- A session can now listen to a Slack direct message as well as a channel. In Listen to Slack, enter a person such as @Nelson, their user ID, or the DM's ID.
- Entering @name turns on Act on anyone's messages, so the other person's messages count. Turn it off if only your own should.
- If nobody or several people match the name, Frontier says so instead of guessing.
