Frontier 0.12.0 — ten small things

- A spent subscription hands the turn to another connected agent instead of failing it.
- MCP catalog: GitHub, filesystem, Postgres, Playwright, Slack, fetch, memory, sequential thinking, Context7.
- Sessions archive when their pull request merges; worktrees of archived sessions can be removed after a set number of days.
- The computer stays awake while an agent or automation works.
- Clone a repository URL into a new project.
- Run an agent's own CLI in the terminal; virtual environments are activated there and named to every agent.
- Cite a selection from a reply in the composer.
- Interface size and spellcheck settings.
