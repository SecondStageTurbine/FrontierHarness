Frontier 0.9.0 — approvals, MCP, usage, preview, fan-out, remote, automations, Gemini, themes

- Approval cards: under Edit files, Claude asks before running a command; Allow or Deny from the conversation.
- MCP servers for the workspace, handed to Claude, Codex and OpenCode on every turn; skills and slash commands listed and offered with `/` in the composer.
- Usage page: tokens, time and cost per agent, project and day.
- Preview panel for the project's dev server, with port discovery.
- Fan-out: one message to several agents, each on its own branch.
- Remote access from another device on your network or tailnet, with a password.
- Automations: daily, every N minutes, or by webhook; each run is a session.
- Gemini CLI as a fourth agent.
- Midnight and Warm themes, and an accent colour.
