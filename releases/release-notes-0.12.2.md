Frontier 0.12.2

- A failed Claude turn now shows Claude's own reason instead of guessing at a sign-in problem; a real sign-in problem is still named as one. The tool's error output is kept in the local backend log for diagnosis.
- An unrecognised model identifier on a Claude row is reported as exactly that, naming the identifiers the tool accepts.
- Team mode is unmistakable: a red Team pill on the toggle, a red edge on the composer, and a strip naming the lead with a Turn off button.
