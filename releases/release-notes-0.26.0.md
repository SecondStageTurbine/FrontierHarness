Frontier 0.26.0

- **New chat**: start a conversation about anything without opening a project. The button sits under New session in the sidebar and works even with no project selected.
- Chats live together under **Chats**, at the top of the project list with a speech-bubble icon, so you can come back to them like any other conversation. Every agent, posture and feature works in them as usual.
- Each agent needs somewhere to work, so Chats has a scratch folder Frontier manages (next to your other managed projects), created the first time you start a chat. The agent is told the conversation is not about a project and not to look through that folder for context.
