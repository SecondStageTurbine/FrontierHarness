Frontier 0.14.0: question cards, a task board, and pop-out panels

- Question cards: when Claude needs a decision only you can make, it pauses and asks in the conversation, with suggested answers and a box for your own, and continues with your answer.
- Task board: each project has a Tasks panel (To do, Doing, Blocked, Done). Team mode puts its plan there, every agent sees the open tasks, and Claude, Codex and OpenCode can update them, so later sessions pick up where earlier ones left off.
- Pop-out panels: Files, Changes, Terminal, Preview or Tasks in their own window for a second monitor, following the project and session open in the main window.
