# Frontier 0.27.3

## Added

- Delete a whole chat: right-click a session in the sidebar and choose **Delete**. Frontier asks first, then removes the conversation for good, with its history and any team workers it started. A worktree the chat made is removed too (its branch and commits stay in the repository); files in the project folder are never touched. A chat that is still working has to be stopped first.
