Frontier 0.25.1

- Discord no longer mistakes Frontier for a game. Frontier's program was `frontier.exe`, and Discord's list of games has a game called "Frontier" with exactly that file name, so Discord showed you as playing it and put its overlay ("Use Discord from the overlay while playing… Go Live") over Frontier. The program is now `frontier-harness.exe`, a name no game on Discord's list uses. The window, shortcuts and Start menu entry are still called Frontier; the update moves your shortcuts to the new program and removes the old one.
