Frontier 0.15.0: projects dashboard, starter prompts, skills catalog

- All projects: a dashboard of every project with its agents' status, last session, git branch and changes, open board tasks, and dev server controls (start, stop, restart, open in browser).
- Starter prompts: a new session offers curated prompts by kind of work, which fill the composer for you to finish.
- Skills catalog (Settings → MCP & Skills): one-click install of curated skills into a project, for Claude Code, Codex and OpenCode alike.
- A repository with no commits yet now shows its real branch name instead of "No".
