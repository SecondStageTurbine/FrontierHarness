# Frontier 0.27.19

## Fixes

- Long conversations stay scrolled to the newest message while a turn runs. The view used to stop part way, or jump, when a turn grew without a new message (routing details, a handover note, a question card) or when the oldest shown messages dropped off the top; you had to drag it back. Sending a message now always brings the end of the conversation into view, and earlier messages no longer disappear off the top mid-turn.
- The goal strip lines up with the composer.
