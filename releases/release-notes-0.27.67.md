## Frontier 0.27.67

- Many more ways of asking for an agent by name are recognised: "Get Fable on it", "give this to Fable", "hand it over to Fable", "have Fable handle it", "bring in Fable", "Fable, take a look", "Fable: review the PR", "@fable". "Don't use Fable" is left alone.
- Slack messages use the same recognition, so a name in a Slack message picks that agent even when the message has no "use …" in it.
