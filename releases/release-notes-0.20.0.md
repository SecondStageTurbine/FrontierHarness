Frontier 0.20.0: agents in your own browser

- Preview → Let agents use a browser now offers "My own Chrome or Edge": agents use the browser you already have open, with your tabs and the sites you are signed in to. Install the Playwright extension in that browser once; paste its token to let agents connect without asking each time.
- Codex can now use Frontier's browser (it used to be refused), and agents are told to use it rather than their own browser tools, whose site approvals cannot be answered during a Frontier turn.
