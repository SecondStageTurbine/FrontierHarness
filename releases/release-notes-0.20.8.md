Frontier 0.20.8

- A team you stopped (or that stopped on an error, or when Frontier closed) can be picked back up: "Continue the team" on its card runs only the unfinished tasks again, with the same lead, plan and posture. Finished tasks stay done, and anything a stopped worker had already written in its own copy of the folder is brought back first, so the next worker starts from it. The lead's final review still covers everything the team did.
- A stopped team's card now says "stopped" instead of still showing its workers as busy.
